# Assumption Mapping Method

Systematically identify, categorize, and interrogate the implicit presuppositions in an argument or plan — revealing the foundations of the reasoning and testing their robustness.

## Assumption Types

### 1. Factual Assumptions
Claims about the state of the world.
**Examples**: "The market will continue to grow", "Users will adopt this feature"
**Test**: Seek empirical evidence.

### 2. Causal Assumptions
Claims about causal relationships.
**Examples**: "Price reduction will increase sales", "Training will improve performance"
**Test**: Check the causal mechanism and look for contrary evidence.

### 3. Normative Assumptions
Claims about values and oughts.
**Examples**: "Growth is good", "Efficiency takes priority over fairness"
**Test**: Question the source of the value and consider alternative values.

### 4. Methodological Assumptions
Claims about research or analysis methods.
**Examples**: "Surveys accurately measure attitudes", "The sample is representative"
**Test**: Check method limitations and alternative methods.

## Mapping Techniques

### Technique 1: Assumption Chain Analysis
Trace each link in the reasoning chain:
```
Conclusion
  ↑ (depends on)
Premise 1
  ↑ (depends on)
Assumption A → Assumption B → Assumption C
```

### Technique 2: Critical Assumption Identification
Find the assumptions with the greatest impact on the conclusion:
- If this assumption is false, does the conclusion collapse?
- Is this the assumption with the highest uncertainty?

### Technique 3: Assumption Stress Testing
Test assumptions under extreme scenarios:
- "If the market shrinks 50%, does this assumption still hold?"
- "What if user behavior is the complete opposite?"

## Interrogation Framework

**Source questions**:
- Where does this assumption come from?
- Whose assumption is it? Whose interests does it serve?

**Evidence questions**:
- What evidence supports this assumption?
- What evidence contradicts it?

**Alternative questions**:
- What alternative assumptions exist?
- What follows if the assumption is reversed?

**Consequence questions**:
- If this assumption is false, what are the consequences?
- How can we monitor whether this assumption continues to hold?
